# Code Persona

**Your code tells a story.**

Code Persona turns your GitHub into a meaningful narrative — revealing how you think, build, and grow, beyond raw stats and charts.

It analyzes real repositories to surface:
- Your development persona
- Key phases in your journey
- Technology evolution
- Insightful repo-level feedback

## How it works
1. Enter a GitHub username  
2. Analyze public activity and projects  
3. Get a shareable Code Persona report

## Why Code Persona
- No vanity metrics
- Insight-first, identity-driven
- Built for resumes, interviews, and reflection

## Analytics

This project uses **Vercel Web Analytics** to track user interactions and performance metrics. For detailed information about setup and usage, see [Vercel Web Analytics Guide](./docs/VERCEL_WEB_ANALYTICS.md).

### Key Tracking
- Page views and unique visitors
- Core Web Vitals (LCP, FID, CLS)
- Real-time usage patterns

### Deployment
Analytics data is collected automatically when deployed to Vercel. To view your analytics:
1. Enable Web Analytics in your Vercel project dashboard
2. Deploy your app to Vercel
3. Visit your analytics dashboard after a few days of user activity
