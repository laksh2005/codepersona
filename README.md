# Code Persona

**Your code tells a story.**

Code Persona turns your GitHub into a meaningful narrative — revealing how you think, build, and grow, beyond raw stats and charts.

It analyzes real repositories to surface:
- Your development persona
- Key phases in your journey
- Technology evolution
- Insightful repo-level feedback

## How it works
1. Enter a GitHub username  
2. Analyze public activity and projects  
3. Get a shareable Code Persona report

## Why Code Persona
- No vanity metrics
- Insight-first, identity-driven
- Built for resumes, interviews, and reflection
